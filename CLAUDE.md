# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

This is a scientific analysis repository for a paper on protein half-life measurement. The project uses isotopic labeling (stable isotope labeling by amino acids, SILAC-style) to measure protein turnover rates in mice, including in a prion disease (FFI) model. It produces all figures and supplementary tables for a manuscript.

## Languages and Environment

**R** (primary, for figures and statistics): managed via conda.

```bash
# Create/activate conda environment
conda env create -f env.yml
conda activate halflife_env
```

**Julia** (for mixture-of-rates modeling): managed via the built-in package manager.

```bash
# Install Julia dependencies (run from repo root)
julia --project=. -e "using Pkg; Pkg.instantiate()"
```

## Running the Analysis

All figures and supplementary tables are generated by running the master script from the repo root:

```bash
Rscript src/halflife_figures.R
```

This sources `src/utils/utils.R` (startup, data loading, output streams) and `src/utils/funcs.R` (mathematical/statistical functions) first, then runs each figure script in order (`src/figs/fig1.R` through `src/figs/figS7.R`).

To run a single figure in isolation, first source the utilities:

```r
library(here)
source(here("src/utils/utils.R"))
source(here("src/utils/funcs.R"))
source(here("src/figs/fig2.R"))  # or whichever figure
```

The Julia mixture model scripts are run separately and their outputs (`data/fig3/` and `data/fig4/table-mixture-model-results.tsv`) are consumed by the R figure scripts:

```bash
julia --project=. src/mixture_of_rates/fig3_mixture_analysis.jl
julia --project=. src/mixture_of_rates/fig4_mixture_analysis.jl
```

## Output

All outputs go to `display_items/`:
- `figure-1.png` through `figure-4.png` and `figure-s*.png` — manuscript figures
- `supplement.xlsx` — all supplementary tables in one Excel workbook
- `table-s01.tsv` through `table-s44.tsv` — same tables as TSV for version control
- `stats_for_text.txt` — in-text statistics written by `write_stats()`

## Architecture

### Data flow

```
data/          →  src/utils/utils.R  →  src/figs/fig*.R  →  display_items/
               →  src/utils/funcs.R  ↗
data/fig3,4/   ←  src/mixture_of_rates/*.jl  (Julia pre-step)
```

### Key utility functions (`src/utils/funcs.R`)

- `Lt()` / `fit_isotopic_thalf()` — isotopic labeling ODE model; fits protein half-life from proportion-labeled timecourse data
- `Pt()` / `calculate_residuals()` — protein abundance ODE model driven by RNA timecourse
- `Pt_mixture()` / `calculate_residuals_mixture()` — mixture-of-rates extension
- `free_lysine(t)` — models heavy lysine availability over time (Fornasiero 2018 parameterization)
- `find_thalf()` / `uniroot` approach — alternative half-life inference from single timepoint
- `label_difference()` — betareg-based test for genotype differences in labeling
- `write_supp_table()` — writes both `.xlsx` sheet and `.tsv` to `display_items/`; maintains the supplement table-of-contents
- `write_stats()` — appends in-text statistics to `display_items/stats_for_text.txt`

### Julia module (`src/mixture_of_rates/TurnoverModels.jl`)

Mirrors the R ODE models but uses `Optim.jl` for fitting. Exports `fit_single_isotopic`, `fit_mixture_isotopic`, `calculate_aic`, `runs_test_residuals`, and `effective_halflife`. Results are written as TSV and read back by the R scripts.

### Data directories

- `data/iqp/` — IQ proteomics output (pivot tables, metadata, LLOQ stats, literature half-lives)
- `data/gtex/` — GTEx v8 PRNP expression by tissue
- `data/crl/` — CRL (Charles River Labs) mouse proteomics data
- `data/aso/` — ASO pharmacokinetics data
- `data/fig4/` — FFI mouse data and Julia mixture model results
- `data/misc/` — external literature data (Li 2017, Sollner 2017)
